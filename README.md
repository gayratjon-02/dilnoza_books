# Dilnoza Books

Android uchun offline kitob yozish ilovasi.

- Boblar va bloklar: sarlavha, stillangan matn, ro'yxat, iqtibos, rasm, jadval
- Har bir o'zgarish avtomatik saqlanadi
- Eksport: PDF, DOCX, EPUB, HTML, TXT, Markdown
- Muqova, avtomatik mundarija, kitob ichida qidirish
- `.dbook` zaxira fayli orqali import va eksport
- PIN va barmoq izi bilan qulf, yorug' va qorong'i tema
- Interfeys tillari: o'zbek, rus, ingliz
- Internet talab qilinmaydi

## Texnologiyalar

Kotlin, Jetpack Compose, Material 3, Hilt, Room, DataStore, kotlinx.serialization, Coil.

## Yig'ish

Talablar: JDK 17, Android SDK.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```
